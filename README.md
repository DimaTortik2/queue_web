# Queue Web - Frontend для Telegram Mini App

Клиентское веб-приложение для управления учебными очередями и обменом местами в режиме реального времени, разработанное специально для Telegram Mini App (TMA).

---

## Технологический стек

* **Базовый фреймворк**: React 18 + Vite 6 + TypeScript 5
* **Стилизация**: Tailwind CSS (плавный бесшовный дизайн без жестких рамок border, тональное разделение фонов, поддержка темной и светлой тем Telegram)
* **Шрифт**: Inter
* **Иконки**: Phosphor Icons (`@phosphor-icons/react`) без подложек
* **Выплывающие шторки**: Vaul (`vaul`) с плоским оверлеем (без backdrop-blur)
* **Серверный стейт**: TanStack Query v5 (React Query)
* **Клиентский стейт**: Zustand
* **Маршрутизация**: React Router v6
* **Уведомления**: Sonner + Telegram Haptic Feedback

---

## Основной функционал

1. **Каталог и создание очередей**:
   * Поиск по предметам и типу работы (лабораторная, семинар, коллоквиум).
   * Горизонтальные фильтры по дисциплинам.
   * Индикатор заполненности (30 слотов) и статус активности (открыта / пауза).
   * Шторка создания новой очереди куратором.

2. **Интерактивная шторка очереди (30 слотов)**:
   * Нажатие на свободный слот - мгновенная запись студента.
   * Свое место подсвечено акцентным тоном.
   * Нажатие на любого участника впереди - вызов шторки предложения обмена местами.
   * Быстрый поиск участника по имени или номеру позиции.
   * Копирование названия очереди в буфер обмена в 1 клик.
   * Панель куратора: продвижение очереди («Следующий»), пауза/возобновление, очистка участников, прямое перемещение слотов («Прямой обмен»), исключение студента («Kick») с подтверждением.

3. **Система обмена местами (Swap System)**:
   * Выбор участников строго впереди с расчетом «на N мест ближе».
   * Прикрепление текстового сообщения к запросу.
   * Шторка ответа на обмен с вводом ответного сообщения при согласии или отказе.
   * Отображение статусов: Ожидает ответа, Принят, Отклонен, Отозван, Истек.
   * Бейдж-счетчик входящих предложений на нижней навигационной панели.

4. **Real-time WebSockets & Экстренные уведомления**:
   * Комнатный сокет `/ws/queue/{subject}`: мгновенная синхронизация 30 слотов между всеми участниками без перезагрузки страницы.
   * Личный сокет `/ws/user/{tg_id}`: пуши входящих обменов, вызов к преподавателю («Вы следующий!»), сдача завершена, исключение из очереди.
   * Закрепленный баннер экстренных событий вверху экрана с интенсивным виброоткликом.

5. **Профиль и администрирование**:
   * Инлайн-редактирование имени профиля (например, добавление группы).
   * Копирование Telegram ID в 1 клик.
   * Управление каталогом дисциплин (создание и удаление предметов куратором).
   * Управление ролями студентов (назначение роли куратора/студента).
   * Dev Switcher для локальной отладки ролей в браузере.

6. **Настройки интерфейса и персонализация**:
   * Закрепление очередей звездочкой в начале каталога с синхронизацией в локальное хранилище.
   * Фильтрация каталога по статусу активности («Все», «Открытые», «На паузе»).
   * Управление тактильным виброоткликом (Haptic Feedback On/Off).
   * Управление закрепленными очередями и сброс настроек в профиле.

7. **Интеллектуальная оценка времени ожидания (ETA) и сетевая надежность**:
   * Точный расчет позиции студента в очереди, числа людей впереди и расчетного времени ожидания.
   * Подсветка статуса «Вы следующий!» в главном баннере очереди.
   * Информативные подсказки при взаимодействии со слотами (защита от записи на паузе, предупреждение при клике на участников позади).
   * Мгновенное определение статуса сети (online/offline) на уровне окна браузера.
   * Нативная защита от случайного смахивания/закрытия окна Telegram Mini App (`enableClosingConfirmation`).

## Запуск в режиме разработки

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального dev-сервера
```bash
npm run dev
```
Приложение запустится на `http://localhost:5173`. Запросы на `/api`, `/queue` и `/ws` автоматически проксируются через Vite на бэкенд `http://localhost:8000`.

### 3. Сборка для продакшена
```bash
npm run build
```
Статические файлы будут скомпилированы в директорию `dist/`.

## Интеграция с Telegram WebApp

* В `index.html` подключен скрипт `https://telegram.org/js/telegram-web-app.js`.
* При запуске вызываются методы `ready()`, `expand()`, `disableVerticalSwipes()` и синхронизация темы (`themeChanged`).
* Системная кнопка `BackButton` синхронизирована с историей переходов `react-router-dom`.
* Нативная кнопка `MainButton` автоматически предлагает открыть активную очередь студента.
* Запросы к API сопровождаются заголовком `X-Telegram-Init-Data: window.Telegram.WebApp.initData`.
